🐧 OSCP / Linux CTF Cheatsheet

Recon → Enumeration → Exploitation → Privesc → Post-Exploitation. For authorized testing / labs (HTB, THM, PG, OSCP exam) only.

0. Methodology

Always: full port scan → service enum → web/app enum → find a foothold → stabilize shell → enumerate locally → privesc → loot flags. Keep notes (CherryTree/Obsidian) and screenshot proof.txt/local.txt.
# Workflow skeleton
mkdir -p ~/ctf/$IP/{scans,exploits,loot,www}
export IP=10.10.10.10
cd ~/ctf/$IP

1. Information Gathering / Reconnaissance

1.1 Host Discovery

nmap -sn 10.10.10.0/24                 # ping sweep
fping -a -g 10.10.10.0/24 2>/dev/null
nmap -PR -sn 10.10.10.0/24              # ARP scan (local subnet)

1.2 Port Scanning (Nmap)

# Fast full TCP port sweep first
nmap -p- --min-rate=5000 -T4 -Pn -oN scans/allports.txt $IP

# Then detailed scan on found ports
nmap -p <ports> -sC -sV -A -oN scans/detailed.txt $IP

# UDP top ports (often missed)
nmap -sU --top-ports 100 -Pn $IP

# All scripts (noisy, last resort)
nmap -p <ports> --script=vuln $IP

# Alternative fast scanners
rustscan -a $IP -- -sC -sV
masscan -p1-65535 $IP --rate=1000 -e tun0
