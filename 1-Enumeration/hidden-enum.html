CTF Recon & Cracking Cheatsheet

Hidden files dhoondhna, plain-text flags/creds hunt karna, protected PDF/Office/KeePass crack karna, backup & history artifacts khangalna, aur Windows AD enumeration — Kali + Windows dono ke liye, CTF labs ke liye banaya gaya quick-reference.

⚠️ Sirf authorized CTF ranges, apni labs (HTB/THM/VulnHub) ya written-permission wale engagements (jaise tumhara CAB / kgshops kaam) ke liye use karo. Kisi bhi system pe bina authorization crack/brute-force mat karo.

Windows 1. Hidden Files & Alt Data Streams Dhoondhna

GUI se chhupi files, system/hidden attribute wali files, ADS (Alternate Data Streams), aur recycle bin ke andar flag dhoondhne ke techniques.

1. CMD se hidden+system files list karo

#01

Attribute H (hidden) aur S (system) dono ko surface karne ke liye:

dir /a:h /s C:\
dir /a /s

2. PowerShell se recursive hidden search

#02
Get-ChildItem -Path C:\ -Hidden -Recurse -ErrorAction SilentlyContinue

3. attrib se file ka hidden/system/readonly flag check/clear karo

#03
attrib flag.txt
attrib -h -s -r flag.txt

4. Explorer me hidden + protected OS files dikhao

#04

View > Options > View tab > "Show hidden files" enable, "Hide protected operating system files" uncheck karo — registry se bhi:

reg add "HKCU\Software\Microsoft\Windows\CurrentVersion\Explorer\Advanced" /v Hidden /t REG_DWORD /d 1 /f
reg add "HKCU\Software\Microsoft\Windows\CurrentVersion\Explorer\Advanced" /v ShowSuperHidden /t REG_DWORD /d 1 /f

5. Alternate Data Streams (ADS) scan karo

#05

Flags aksar file.txt:flag.txt type ADS me chhupaye jaate hain.

dir /r
Get-Item -Path .\file.txt -Stream *
Get-Content -Path .\file.txt -Stream flag

6. Sysinternals streams.exe se bulk ADS scan

#06
streams.exe -s C:\Users\Public

7. Recycle Bin manually khangalo

#07
dir /a C:\$Recycle.Bin\ /s
Get-ChildItem -Force 'C:\$Recycle.Bin' -Recurse

8. NTFS Alternate data stream wali deleted/orphan file dhoondo

#08
fsutil file queryEA C:\path\file.txt
icacls C:\path\file.txt

9. where.exe se puri drive me filename pattern dhoondo

#09
where /r C:\ flag*.txt
where /r C:\ *.kdbx

10. Everything / es.exe (voidtools) se fast indexed search

#10
es.exe flag
es.exe -a flag.txt

11. Desktop.ini / thumbs.db ke andar metadata check karo

#11

Chhupi notes/paths kabhi kabhi desktop.ini ya folder icon references me milte hain.

type desktop.ini
Get-Content thumbs.db -Encoding Byte | more

12. forfiles se system-wide pattern recursive search (dir se fast)

#12
forfiles /P C:\ /S /M flag*.* /C "cmd /c echo @path"

Kali / Linux 2. Hidden Files Dhoondhna

Dotfiles, extended attributes, loopback mounts, aur SUID/capability trail — Linux CTF boxes me standard enumeration.

13. Dotfiles aur hidden dirs recursively list karo

#13
ls -la
find / -name ".*" -type f 2>/dev/null

14. find se naam/pattern se flag file dhoondo

#14
find / -iname "flag*" 2>/dev/null
find / -iname "*.txt" -newer /etc/hostname 2>/dev/null

15. Hidden files ko size/time se filter karo

#15
find / -type f -mtime -1 2>/dev/null
find / -type f -size -5k -name "*.txt" 2>/dev/null

16. Extended attributes (xattr) check karo

#16
getfattr -R -d / 2>/dev/null | grep -i flag
lsattr -R / 2>/dev/null | grep -v '^----'

17. SUID/SGID binaries dhoondo (privesc path bhi)

#17
find / -perm -4000 -type f 2>/dev/null
find / -perm -2000 -type f 2>/dev/null

18. World-writable aur unusual ownership files dhoondo

#18
find / -writable -type f 2>/dev/null | grep -v proc

19. Mounted/loopback images aur hidden partitions check karo

#19
lsblk
mount | grep -i loop
file disk.img

20. binwalk se embedded/hidden files extract karo image/binary se

#20
binwalk -e suspicious.jpg
binwalk --dd='.*' firmware.bin

21. exiftool/steghide se steganography check karo

#21
exiftool image.png
steghide extract -sf image.jpg
zsteg image.png

22. locate/updatedb se fast system-wide search

#22
updatedb 2>/dev/null; locate flag

23. tar/zip archives ke andar hidden entries list karo

#23
tar -tvf archive.tar
unzip -l archive.zip

24. /proc aur /tmp me runtime artifacts check karo

#24
ls -la /tmp /var/tmp /dev/shm
cat /proc/*/cmdline 2>/dev/null

Cross-platform 3. Plaintext Flags & Credentials Hunt

Files ke andar flag format (flag{...}, CTF{...}, password strings) grep/search karna — Windows aur Linux dono.

25. grep se recursive flag-format search (Linux)

#25
grep -r -i "flag{" / 2>/dev/null
grep -rE "(flag|ctf)\{[A-Za-z0-9_\-]+\}" / 2>/dev/null

26. grep se password/secret keyword hunt

#26
grep -rniE "(password|passwd|secret|api_key|token)\s*=" / 2>/dev/null

27. Windows findstr se equivalent recursive search

#27
findstr /s /i /m "flag{" C:\*.*
findstr /s /i "password" C:\Users\*.txt

28. PowerShell Select-String se pattern search

#28
Get-ChildItem -Recurse -ErrorAction SilentlyContinue | Select-String -Pattern "flag\{.*\}"

29. strings se binary/non-text files ke andar printable text nikaalo

#29
strings suspicious.bin | grep -i flag
strings -n 8 memory.dmp | grep -iE "pass|flag"

30. Config files, .env, aur history files me hardcoded creds dhoondo

#30
find / -iname "*.env" -o -iname "*.ini" -o -iname "*.conf" 2>/dev/null
cat .env 2>/dev/null
type web.config 2>nul

31. Environment variables aur process memory me creds check karo

#31
env
Get-ChildItem Env:
ps aux | grep -i pass

32. Browser saved sessions/cookies me flag dhoondo (CTF web challenges)

#32
grep -ri "flag" ~/.mozilla/firefox/*/cookies.sqlite
grep -ri "flag" ~/.config/google-chrome/Default/Cookies

Kali 4. Protected Files Crack Karna (PDF / Office / KeePass / Archive)

Password-protected PDFs, Office docs, KeePass .kdbx databases, aur zip/rar archives ke liye hash extraction + offline cracking workflow (John the Ripper + Hashcat).

33. PDF se crackable hash extract karo

#33
pdf2john protected.pdf > pdf.hash
john --wordlist=/usr/share/wordlists/rockyou.txt pdf.hash
john --show pdf.hash

34. PDF hash ko Hashcat (mode 10500/10400) se crack karo

#34
hashcat -m 10500 pdf.hash /usr/share/wordlists/rockyou.txt
hashcat -m 10400 pdf.hash rockyou.txt --force

35. Office docs (.docx/.xlsx/.pptx) se hash extract karo

#35
office2john protected.docx > office.hash
john --wordlist=rockyou.txt office.hash

36. Office hash ko Hashcat se (mode 9500/9600) crack karo

#36
hashcat -m 9500 office.hash rockyou.txt
hashcat -m 9600 office.hash rockyou.txt

37. KeePass .kdbx database se hash extract karo

#37
keepass2john vault.kdbx > kdbx.hash
john --wordlist=rockyou.txt kdbx.hash
john --show kdbx.hash

38. KDBX hash ko Hashcat se (mode 13400) crack karo

#38
hashcat -m 13400 kdbx.hash rockyou.txt
hashcat -m 13400 kdbx.hash rockyou.txt -r rules/best64.rule

39. KeePass key-file + master password combo (keyfile-based) attack

#39

Agar keyfile mila hai to usay hash extraction ke time include karo:

keepass2john -k keyfile.key vault.kdbx > kdbx.hash

40. ZIP archive crack karo (zip2john / fcrackzip)

#40
zip2john protected.zip > zip.hash
john --wordlist=rockyou.txt zip.hash
fcrackzip -D -u -p rockyou.txt protected.zip

41. RAR archive crack karo (rar2john)

#41
rar2john protected.rar > rar.hash
john --wordlist=rockyou.txt rar.hash

42. 7z archive crack karo

#42
7z2john.pl protected.7z > sevenz.hash
john --wordlist=rockyou.txt sevenz.hash

43. BitLocker/LUKS encrypted volume ke hash nikaalo (forensics CTF)

#43
bitlocker2john -i encrypted.vhd > bl.hash
luks2john encrypted.img > luks.hash

44. Mask attack + rule-based cracking (smart bruteforce, jab wordlist fail ho)

#44
hashcat -m 13400 kdbx.hash -a 3 ?u?l?l?l?l?d?d?d
hashcat -m 13400 kdbx.hash rockyou.txt -r rules/rockyou-30000.rule

WindowsKali 5. Backup & History Artifacts

Shell history, VSS/shadow copies, backup files, aur temp/log artifacts jaha creds ya flags accidentally reh jaate hain.

45. Bash/Zsh history files check karo

#45
cat ~/.bash_history
cat ~/.zsh_history
history

46. PowerShell command history check karo

#46
Get-History
type $env:APPDATA\Microsoft\Windows\PowerShell\PSReadLine\ConsoleHost_history.txt

47. Windows Volume Shadow Copies (VSS) list karo

#47
vssadmin list shadows
wmic shadowcopy list brief

48. Shadow copy ko mount karke purani file versions access karo

#48
mklink /d C:\shadow_copy \\?\GLOBALROOT\Device\HarddiskVolumeShadowCopy1\
dir C:\shadow_copy

49. .bak / .old / backup-naming pattern wali files dhoondo

#49
find / -iname "*.bak" -o -iname "*~" -o -iname "*.old" 2>/dev/null
dir /s /b C:\*.bak C:\*.old

50. Windows Backup / wbadmin history check karo

#50
wbadmin get versions
wbadmin get history

51. Recent Files / Jump Lists / MRU registry keys check karo

#51
dir "%APPDATA%\Microsoft\Windows\Recent"
reg query "HKCU\Software\Microsoft\Windows\CurrentVersion\Explorer\RecentDocs"

52. Prefetch, Event Logs aur SRUM se execution history nikaalo

#52
dir C:\Windows\Prefetch
wevtutil qe Security /c:20 /rd:true /f:text

53. Git repo ke .git folder se commit history/flags check karo

#53
git log --all -p | grep -i flag
git stash list
git show --all

54. Trash/.local/share/Trash me deleted file remnants check karo (Kali/Linux)

#54
ls -la ~/.local/share/Trash/files/
cat ~/.local/share/Trash/info/*.trashinfo

Active Directory 6. Windows AD Enumeration

Domain enumeration, user/group/ACL recon, aur common AD attack-path tools — Kali attack box se authorized AD lab/CTF range (jaise HTB, THM AD boxes) ke liye.

55. Domain info, controllers aur trust relationships enumerate karo

#55
nltest /dclist:domain.local
Get-ADDomain
Get-ADTrust -Filter *

56. BloodHound se attack-path collection (SharpHound ingestor)

#56
SharpHound.exe -c All
bloodhound-python -u user -p pass -d domain.local -c All

57. PowerView se users/groups/ACL enumeration

#57
Get-NetUser
Get-NetGroup "Domain Admins"
Get-ObjectAcl -SamAccountName svc_account -ResolveGUIDs

58. LDAP se anonymous bind/enumeration try karo

#58
ldapsearch -x -H ldap://dc.domain.local -b "dc=domain,dc=local"
ldapdomaindump dc.domain.local -u 'domain\user' -p pass

59. Kerberoasting se service account hash nikaalo

#59
GetUserSPNs.py domain.local/user:pass -dc-ip 10.10.10.10 -request
Invoke-Kerberoast | fl

60. AS-REP Roasting (pre-auth disabled accounts) try karo

#60
GetNPUsers.py domain.local/ -usersfile users.txt -no-pass -dc-ip 10.10.10.10

61. SMB shares enumerate karo (crackmapexec/netexec + smbclient)

#61
netexec smb 10.10.10.10 -u user -p pass --shares
smbclient -L //10.10.10.10 -U user

62. rpcclient se null-session enumeration

#62
rpcclient -U "" -N 10.10.10.10
rpcclient $> enumdomusers

63. enum4linux-ng se full SMB/AD recon

#63
enum4linux-ng -A 10.10.10.10

64. SYSVOL/GPO me stored legacy GPP passwords dhoondo

#64
findstr /S /I cpassword \\domain.local\SYSVOL\domain.local\Policies\*.xml
gpp-decrypt <cpassword-value>

65. DCSync/NTDS.dit se credential extraction (post-compromise)

#65
secretsdump.py domain.local/user:pass@10.10.10.10
secretsdump.py -ntds ntds.dit -system SYSTEM LOCAL
Workflow tip: pehle (1) & (2) se hidden/flag files locate karo → (3) se content pattern-match karo → agar file encrypted mile to (4) ke hash-extract + crack steps use karo → (5) se forensic backup trail bhi cross-check karo → agar target AD environment hai to (6) parallel chalao. Hashcat ke mode numbers tool version ke hisaab se change ho sakte hain — hashcat --help | grep -i "mode" se confirm kar lena.
